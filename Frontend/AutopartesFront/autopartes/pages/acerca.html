Síntesis del TP

Motorix Autopartes es una aplicación web desarrollada como Trabajo Práctico Integrador de la asignatura Programación II (UTN - Facultad Regional Córdoba, Tecnicatura Universitaria en Programación, Comisión 1W1, ciclo lectivo 2026).

El sistema está orientado a la gestión y venta de autopartes de una empresa automotriz. Permite a los clientes consultar el catálogo, filtrar repuestos por modelo de vehículo y registrarse; y a los administradores gestionar el inventario, los precios, el stock, las asociaciones entre autos y autopartes, y el seguimiento de órdenes con un panel de resumen.

La solución se compone de tres partes principales: una base de datos relacional en SQL Server, una API REST en ASP.NET Core (.NET 8) con Entity Framework Core, y un frontend estático desarrollado con HTML, CSS y JavaScript.

Tecnologías y funcionalidades

  • Backend: C#, .NET 8, ASP.NET Core Web API, Entity Framework Core 8.
  • Base de datos: Microsoft SQL Server / SQL Server Express.
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5.
  • Seguridad: autenticación por cookies (cliente y administrador) y contraseñas almacenadas con hash.

Funcionalidades destacadas

  • Catálogo de autopartes con precio vigente, stock e imagen.
  • Búsqueda y filtrado por marca, modelo, año y categoría.
  • Registro e inicio de sesión de clientes.
  • Panel de administración: inventario, modelos, compatibilidades, órdenes y resumen de ventas.
